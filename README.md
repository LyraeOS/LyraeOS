# What is it?
LyraeOS is a 64bit operating system using the limine bootloader. It is designed to be unix-kinda-like os meaning that it will have somewhat similar features to other unix based operating systems

# Goals
## Current Goals
- GUI
- File System
- SMP
- Scheduler
  - APIC ish

## Future Goals
- ELF binaries and userspace
- Multi-processing Conway's Game of Life
- Filled Polygons

## Current Progress
- Very basic shell
- Conway's game of life
- Minesweeper
- Serpinksi triangles
- Memory Allocator
- Filled Triangles

# Naming


The name Lyrae is named after the "double double" system, also known as ε Lyrae, in the Lyra constellation. It has two sets of binary star systems.
