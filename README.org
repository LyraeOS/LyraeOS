* What is it?
  LyraeOS is a 64bit operating system using the limine bootloader. It is designed to be unix-kinda-like os meaning that it will have somewhat similar features to other unix based operating systems.
  This project is not intended to be compatible with linux.
* Goals
** Current Goals
    - Compositor
    - GUI
    - File System
    - SMP
    - Scheduler
    - APIC ish
** Future Goals
    - ELF binaries and userspace
    - Multi-processing Conway's Game of Life
    - Filled Polygons
** Currently completed
    - Very basic shell
    - Filled Triangles
    - Memory Allocator
    - Conway's game of life
    - Minesweeper
* Running
** Requirements
   - GCC
   - Make
   - Xorriso
   - NASM
   All of the requirements are also in the flake.nix if you are on nixos
** Build
   #+begin_src shell
   make
   #+end_src
** Running
*** BIOS
    #+begin_src shell
    make run-bios
    #+end_src
*** UEFI
    #+begin_src shell
    make run-efi
    #+end_src

* Naming
    The name Lyrae is named after the "double double" system, also known as ε Lyrae, in the Lyra constellation. It has two sets of binary star systems.
